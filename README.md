A modern, responsive portfolio website showcasing my skills, projects, and experience as a MERN Developer. Built with React, Vite, and Tailwind CSS for a clean and professional look.

## 🚀 Features

- **Responsive Design**: Optimized for all devices and screen sizes
- **Smooth Animations**: Fade-in effects and transitions for enhanced user experience
- **Interactive Components**: Hover effects, scroll-based navigation, and dynamic content
- **Sections Include**:
  - Introduction with background image
  - About Me
  - Skills showcase
  - Project portfolio
  - Blog posts
  - Contact information
- **Downloadable CV**: Direct download link for resume
- **Social Links**: Easy access to professional profiles

## 🛠️ Tech Stack

- **Frontend**: React 19
- **Build Tool**: Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Font Awesome
- **Deployment**: Ready for static hosting (Vercel, Netlify, etc.)

## 📋 Prerequisites

- Node.js (version 16 or higher)
- npm or yarn

## 🔧 Installation & Setup

1. **Clone the repository**
   \`\`\`bash
   git clone https://github.com/KarmPandya007/Karm-Portfolio-Updated-Light-Theme.git
   cd Karm-Portfolio-Updated-Light-Theme
   \`\`\`

2. **Install dependencies**
   \`\`\`bash
   npm install
   \`\`\`

3. **Start the development server**
   \`\`\`bash
   npm run dev
   \`\`\`

4. **Open your browser**
   Navigate to `http://localhost:5173` (or the port shown in terminal)

## 📜 Available Scripts

- `npm run dev` - Start development server with hot reload
- `npm run build` - Build for production
- `npm run preview` - Preview production build locally
- `npm run lint` - Run ESLint for code quality checks
